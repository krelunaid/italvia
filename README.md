# ITALVIA

**Twój bezpieczny dom we Włoszech** · **La tua casa sicura in Italia**

Concierge immobiliare Italia–Polonia. Non è un catalogo: è l’app personale dell’agente che accompagna un compratore polacco dalla prima idea alle chiavi — in polacco e in italiano.

## Due porte

| | Cliente | Agente |
|---|---|---|
| Vista | Case, costo totale, dossier, percorso, offerte | Desk, terrazzo live, trattative, clienti |
| Login | Google, X, oppure e-mail | Utente `italvia` (vale anche `italva`) |

Password di prova (solo per questa copia): `agente2026`

## Cosa c’è dentro

- Selezione di case italiane con onestà stagionale (agosto vs gennaio)
- Costo totale dell’acquisto, non solo il prezzo dell’annuncio
- Dossier sicurezza e percorso guidato
- Offerta informale → proposta ufficiale bilingue → caparra
- Diretta dal terrazzo: invito a tutti o a contatti scelti, chat privata sì/no
- Chiara, concierge AI, in polacco o italiano

## Avvio

```bash
npm install
npm run dev
```

App su `http://localhost:8080`. Build: `npm run build`.

Stack: TanStack Start, Postgres / PGLite, Better Auth, Tailwind.
